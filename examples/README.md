# SatisPlanner v1.0.1 Example Plans

These canonical schema-v5 plans use only the versioned fallback catalog and original generic
SatisPlanner icons. They contain no Satisfactory artwork, raw Docs data, save data or personal paths.

| Plan | What it demonstrates | Golden result |
| --- | --- | --- |
| `coal-mk5-bottleneck.satisplan.json` | Pure Miner Mk.3 at 250% feeding a Mk.5 belt | 1,200/min requested, 780/min capacity, 420/min lost; Mk.6 clears it |
| `independent-machines.satisplan.json` | Two Constructors and one Assembler with isolated settings | Plate 20/min; slooped 200% Rod 60/min; two-sloop 150% Assembler 15/min |
| `fluid-pipeline-capacity.satisplan.json` | Pure oil extraction through Pipeline Mk.1 | 600 m³/min requested, 300 m³/min capacity, 300 m³/min lost; Mk.2 clears it |

Open **Save, import & migration**, choose a `.satisplan.json` file, select **Preview plan import**,
review the snapshot/profile report, then choose **Apply imported plan**. The source remains read-only.

Example screenshots may be generated locally from generic fallback visuals. Screenshot exports that
show user-imported game artwork must not be committed or attached to SatisPlanner releases.
