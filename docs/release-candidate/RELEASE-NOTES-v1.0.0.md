# SatisPlanner v1.0.0

First stable release of the offline-first Satisfactory 1.2 factory planning desktop application.

## Highlights

- physical machine instances with independent clock, Power Shard, Somersloop and standby settings;
- resource purity/extractor tiers, conveyor/pipeline capacity, steady-state flow and power diagnostics;
- searchable React Flow workspace, keyboard workflow, groups, minimap and accessible diagnostics;
- versioned save/autosave/recovery, canonical import/export and upstream `.fcs` preview migration;
- Satisfactory 1.2 profiles, independent Turkish/English UI and game-data locale metadata;
- three tested example plans and a first-run offline onboarding guide;
- current-user Windows installer plus Windows/Linux/macOS/web portable artifacts;
- SHA-256 manifest, SPDX JSON SBOM, third-party notices and GitHub/Sigstore attestations.

Artifacts are unsigned. Verify checksums and attestations before use. Read
[Known Limitations](KNOWN-LIMITATIONS.md), [Credits](CREDITS.md) and the
[Getting Started guide](../user-guide/GETTING-STARTED.md).
