# S12-T03 — Accessibility ve Visual States

**Amaç:** Graph editor'ı klavye, screen reader ve renk görme farklılıklarıyla kullanılabilir yapmak.

**Çıktılar:** keyboard flow; ARIA labels/live diagnostics; focus styles; icon+text status; contrast tokens; reduced-motion policy.

**Kabul:** Library→canvas→inspector keyboard-only; node/edge accessible name item/building+status içerir; kırmızı/yeşil tek anlam kanalı değildir; focus kaybolmaz; zoom kontrolleri etiketlidir.

**Test/Kanıt:** Axe smoke, keyboard E2E, visual snapshots ve manual checklist.

**Bağımlılık:** S12-T01,T02. **Boyut:** M.
